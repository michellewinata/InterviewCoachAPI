# InterviewCoach
Interview Coach allows users to practice answering interview questions in a simulated interview environment. By using speech recognition, users can respond naturally while the application transcribes their answers in real time, helping them build confidence and prepare for real interviews.

Features:
Real-Time Speech Recognition — Converts spoken answers into text during practice sessions.
Interview Practice — Practice answering interview questions in a simulated interview environment.
Live Transcription — View recognized speech as you speak.
English and Indonesian Support — Supports interview practice in both languages.
User-Friendly Interface — Provides a simple and intuitive experience for interview preparation.
Analysis Report — Review interview responses and performance insights to identify strengths and areas for improvement.
