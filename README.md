# InterviewCoach
Interview Coach allows users to practice answering interview questions in a simulated interview environment. By using speech recognition, users can respond naturally while the application transcribes their answers in real time, helping them build confidence and prepare for real interviews.

## Features
- **Real-Time Speech Recognition:** Converts spoken answers into text during interview practice sessions.
- **Interview Practice:** Simulates interview scenarios to help users prepare for real-world interviews.
- **Live Transcription:** Displays recognized speech in real time.
- **Bilingual Support:** Supports interview practice in both English and Indonesian.
- **User-Friendly Interface:** Provides a simple and intuitive interface for a smooth practice experience.
- **Analysis Report:** Generates performance insights to help users identify their strengths and areas for improvement.
